Vos étiquettes

Saisissez les articles à la main ou importez-les (fichier Excel / CSV, ou dépôt) : tout arrive dans la même liste et sur la même planche A4, à droite. Le format (60 × 45 mm, 18 par planche) et la disposition sont réglés d'office : ne les ouvrez que pour les changer.

Code barre facultatif : sans code, l'étiquette garde la disposition classique.
📋 Coller depuis Excel

Copiez dans Excel les colonnes Ref · Code barre · Description · PV, dans cet ordre, avec ou sans ligne d'en-tête, puis collez ici. Les lignes s'ajoutent à la fin. Vous pouvez aussi coller directement dans un champ de saisie.
Astuce : mettez la colonne Code barre au format Texte dans Excel, sinon les codes longs arrivent abîmés (4,00638E+12).

Disposition des éléments

Faites glisser chaque élément ; les poignées bleues règlent la largeur (texte) ou la taille (image, code-barres). Rien ne peut déborder de l'étiquette ; un texte trop long rétrécit, puis se termine par « ... ». Il y a deux dispositions : les étiquettes avec un code-barres valide utilisent la seconde.

Images produits
Imprimer l'image produit sur les étiquettes
Récupérer via un relais les images bloquées (CORS) — recommandé

Les images viennent de la colonne Image de l'import ; ajoutez-en ci-dessous (lien ou fichier). Par défaut l'image se place au centre, sous le texte : placer l'image dans le volet Disposition.

Imprimez à 100 % (taille réelle) pour respecter les dimensions au millimètre et garder des codes-barres lisibles.
